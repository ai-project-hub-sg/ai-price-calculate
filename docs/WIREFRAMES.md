**页签顺序**：结果表 / 汇总页 / 中转站管理 / 官方价目 / 单次估算。


## 1. 档案栏（多配置档案，F9/F13）

```
档案: [主力测算 ▾]  ✎重命名  ⧉复制档案  ＋新建  🗑删除
      └ 下拉: ●主力测算(当前)  ○低价路线对比  ○高缓存场景 ……
```

- 一切换即整体替换下方所有区的数据源；每档案独立持久化。
- ⧉复制档案 = 深拷贝整树（含全部站点/提供商/覆盖），生成「xx 副本」，切到副本继续编辑。

## 2. 场景栏（F2/F3/F12 账户级）

| 控件 | 行为 |
|---|---|
| promptTokens | 决定命中档位；改值即全表重算 |
| 配比三项 | 输入/缓存读/输出；和≠100% 下方灰字显示归一化值 |
| 预设 | 保存/应用/删除命名配比 |
| ☑非高峰 | DeepSeek 类 ×offPeakRatio |
| ☑分档计价 | 账户级总开关；关掉→全树分档失效（不改子级状态） |
| 汇率 | auto: 显示来源+时间+刷新；manual: 输入框 |

## 4. 中转站管理（F4-F6/F12/F13）——树形编辑器

```
[＋新建站点]
▼ 示例站 A   USD  默认折0.8  ☑分档 ☑启用   [编辑][⧉复制][🗑]
  ├─ ▼ 提供商: 示例站 A（默认商）  折:继承  ☑分档 ☑启用  [编辑][⧉][🗑-灰]
  │    范围: anthropic,google / 全部系列
  │    厂商开关: google☑分档
  │    ├─ 覆盖: gpt-6.2-astra  折0.6  ☑分档        [编辑][⧉][🗑]
  │    └─ 覆盖: claude-opus-5-5  自定价(2档)✎      [编辑][⧉][🗑]
  └─ ▶ 提供商: 批发上游  折0.65  ☑分档 ☐停用      [编辑][⧉][🗑]
       范围: 全部厂商 / 全部系列
▼ 便宜站 B   CNY  默认折0.7  ☑分档 ☑启用   [编辑][⧉复制][🗑]
  └─ ▼ 提供商: 便宜站 B（默认商）…

提供商编辑抽屉:
  名称[__] 启用☑ 默认折扣[继承▾|0.65] ☑分档
  提供范围: 厂商[anthropic☑ google☑ …] → 系列[claude-sonnet☑ …] →
            或精确模型白名单[搜索添加________]
  模型覆盖: [＋添加] 模型▾ → [折扣⦿|自定义价○] → tiers 编辑器
```

- 每个节点行尾操作：编辑/⧉复制/🗑；复制=克隆该节点整棵子树。
- 默认提供商名牌匾随站名联动；最后一个提供商 🗑 置灰。

## 8. 状态映射

| 状态 | 触发 | 表现 |
|---|---|---|
| 空 | 无档案/无站点/汇总无行 | 插画占位+引导按钮（新建站/一键更新） |
| 加载 | 汇率获取/价目更新任务 | 骨架行+任务进度条（jobs 轮询） |
| 错误 | API 不可达/导入校验失败 | 顶部横幅+降级 localStorage；逐条错误列表 |
| 降级 | 后端断开 | 所有写操作仍可用，仅落 localStorage，恢复后同步 |
