## 1. 档案栏（F9/F13）

```
档案: [主力测算 ▾]  ✎重命名  ⧉复制档案  ＋新建  🗑删除
      └ 下拉: ●主力测算(当前)  ○低价路线对比  ○高缓存场景 ……
```

- 每个档案独立持久化「场景+汇率+站点树」；切换即整体替换数据源，互不覆盖。
- ⧉复制档案 = 深拷贝整树（含站点/提供商/覆盖）生成「xx 副本」。

## 2. 场景栏（F2/F3/F12 账户级）

| 控件 | 行为 |
|---|---|
| promptTokens | 决定命中档位；改值即全表重算 |
| 配比三项 | 输入/缓存读/输出；和≠100% 下方灰字显示归一化值 |
| 配比预设 | 保存/应用/删除命名预设，示例：对话均衡 5/3/2、高缓存读 3/6/1、长文写作 9/0.5/0.5 |
| ☑非高峰 | DeepSeek 类 ×offPeakRatio |
| ☑分档计价 | 账户级总开关；关掉→全树分档失效（不改子级状态） |
| 汇率 | auto: 显示来源+时间+刷新；manual: 输入框。仅用于「换汇列」 |

**价格口径（统一约定）**
- **不换汇列**：模型**官方币种**原值——USD 计价模型（OpenAI/Claude/Gemini/Grok/DeepSeek/Z.AI）显示美元数、CNY 计价模型（Kimi/国内 GLM）显示人民币数；每行按模型而定，列头不带固定单位。
- **换汇列**：一律折算成**人民币 ¥**（USD 值 × 汇率；CNY 值照原样）。全表该列单位恒为 ¥，可直接排序比较。
- 站点/提供商均无币种属性；自定义基础价的币种=该模型官方币种（跟随模型，无需选择）。

## 3. 结果表（F7/F14）——单一明细大表

**列固定、语义单一；所有变化（档案/站/商/模型/档位）都摊成行。** 一行 = 一条「配置×站×提供商×范围内模型」的计算结果，跨全部启用档案铺开。排序=点列头；筛选=行减少。

```
筛选: 配置[全部▾] 站[全部▾] 提供商[全部▾] 厂商[全部▾] 系列[全部▾] 搜索[____]   共 214 行
┌─────────┬────────┬─────────┬──────────┬─────────┬────────────┬────┬─────┬────────┬──────────┬─────────┐
│ 配置     │ 站      │ 提供商   │ 厂商      │ 系列     │ 模型        │档位 │折扣  │ 不换汇  ↕│ 换汇(¥)  ↓│ 官方(¥) │
├─────────┼────────┼─────────┼──────────┼─────────┼────────────┼────┼─────┼────────┼──────────┼─────────┤
│ 主力测算 │ 便宜站B │ 默认商   │ moonshot │ kimi-k3 │ kimi-k3    │ —  │ 0.8 │ ¥29.50 │ ¥29.50   │ ¥36.88  │
│ 低价对比 │ 便宜站B │ 默认商   │ deepseek │ v4      │ v4-pro     │ —  │ 0.7 │ $2.30  │ ¥15.37   │ ¥21.96  │
│ 主力测算 │ 示例站A │ 批发上游 │ anthropic│ sonnet  │ sonnet-5.5 │≤1M │ 0.7 │ $1.69  │ ¥11.98   │ ¥14.98  │
│ 低价对比 │ 示例站A │ 主商     │ google   │ g-flash │ 3.8-flash  │ —  │ 0.6 │ $0.45  │ ¥3.19    │ ¥5.33   │
└─────────┴────────┴─────────┴──────────┴─────────┴────────────┴────┴─────┴────────┴──────────┴─────────┘
```

- **不换汇**：模型官方币种原值（$ 或 ¥ 按行不同）；排序时按币种分组（¥ 组在前、$ 组在后，组内比大小）。
- **换汇(¥)**：恒人民币，真实成本排序列——点它升序第一行即「全部配置里最便宜组合」。
- **官方(¥)**：同模型官方折算价基准列，行内直接看省了多少。
- **档位**列显示命中档（`≤200K`/`>272K`/—）；**折扣**列显示生效折扣+来源色标（官方价灰/折扣蓝/自定价橙）。
- 行只统计：档案启用中的站 → 启用中的提供商 → 提供范围内的模型。
- 筛选器：配置/站/提供商/厂商/系列 五个多选下拉 AND + 模型名搜索框；无行时空态提示放宽条件。

## 7. 状态映射

| 状态 | 触发 | 表现 |
|---|---|---|
| 空 | 无档案/无站点/汇总无行 | 占位+引导按钮（新建站/一键更新） |
| 加载 | 汇率获取/价目更新任务 | 骨架行+任务进度（jobs 轮询） |
| 错误 | API 不可达/导入校验失败 | 顶部横幅+降级 localStorage；逐条错误列表 |
| 降级 | 后端断开 | 写操作仍可用，仅落 localStorage，恢复后同步 |
