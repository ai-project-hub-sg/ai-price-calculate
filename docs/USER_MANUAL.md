# 使用手册

面向使用者的功能操作说明。界面为单页应用，顶部依次是：档案区 → 场景条 → 五个页签（结果表 / 中转站管理 / 官方价目 / 单次估算 / 账单核对）。

## 1. 结果表

横轴：配置 × 站 × 提供商 × 模型，全部档案铺成明细行。

| 列 | 含义 |
|---|---|
| 配置/站/提供商/厂商/系列/模型 | 归属维度 |
| 档位 | promptTokens 命中的档（如 `≤272K`、`>272K`、`全部`） |
| 折扣 | 该行生效的折扣链终值；颜色区分基价来源（官价/自定价/纯折扣） |
| 配比(入\|读\|写\|出) | 该行实际命中的 token 配比 |
| 中转站价格(¥) | 归一化代币价 ÷ 充值比例，直接按人民币显示（默认排序列，升序=最便宜） |
| 官价(原币) | 同档同配比官方价，按官方币种显示（$ 或 ¥） |
| 官价换汇(¥) | 官方价按当前汇率折人民币——与中转站价对照看价差 |

- **筛选**：表头上方 5 个多选下拉（配置/站/商/厂商/系列），同筛选内 OR、筛选间 AND、选项联动（选了 anthropic 系列就只剩 claude 系）；右侧搜索框匹配模型 id
- **排序**：点列头切换升/降序

## 2. 档案与场景条

- **档案**：顶部下拉切换；「新建/复制/✎重命名/🗑删除/导入/导出」按钮。演示档案带 `·演示` 后缀；「载入演示」只补不覆盖、「清空演示」需确认
- **promptTokens**：本次估算的输入侧 token 量（= 输入+缓存读+缓存写），决定命中哪一档
- **配比**：输入/缓存读/缓存写/输出 四个权重（自动归一化），是场景级默认值，可被下级覆盖
- **预设**：5 组社区实测场景配比（编码智能体/Claude轨迹/对话/长文/无复用）
- **配比预设…**：抽屉里三层——公共默认、厂商级（「载入社区预设」一键补齐 8 家）、模型级
- **☐非高峰**：命中模型 `offPeakRatio` 闲时折扣
- **分档计价（档案级）**：关 = 全部模型按首档价
- **汇率**：自动（er-api 实时）或手动输入

## 3. 中转站管理

三级树：站点 → 提供商 → 模型覆盖。节点右侧操作按钮（编辑/⧉复制/🗑/＋覆盖）。

### 站点

| 字段 | 说明 |
|---|---|
| 名称/URL/备注 | URL 仅备注用 |
| 默认折扣 | (0,10]，提供商未自填时继承 |
| **充值比例** | ¥1 → N 代币。一般 1；部分站 1 元=15~20 代币。结果表的中转站价格 = 代币价 ÷ 充比 |
| 分档计价 / 启用站点 | 关分档=统一首档；停用站不产结果行 |
| 配比 | 继承上级｜自填四分量 |
| **提供范围** | 站点能提供的模型上界——提供商只能在其内选 |

### 提供商

- 名称 / 启用 / 分档计价
- **默认折扣**：继承站默认（显示继承值）｜自填
- **提供范围**：级联下拉——厂商→系列→模型三列向右展开，三态勾选；列头 全/反 按钮按层级生效；可选项已被站点范围裁剪（结构保证 商范围 ⊆ 站范围）
- **厂商级折扣**：8 厂商各一输入框，空=走默认链，可 >1（如 claude 溢价 1.3）
- **模型例外折扣**：＋选择模型 → 填倍率（如 luna ×10）；写入 `modelOverrides.discount`，不需建完整覆盖
- **厂商级分档开关**：按厂商关分档
- **配比**：继承｜自填

### 模型覆盖（树节点「＋覆盖」）

- **折扣**：数字，空=走折扣链
- **自定义基础价**：勾选后出现分档编辑器（不勾则不显示，与折扣互斥）
- **分档编辑器**：每档 `[≤/</>/≥/全部] 阈值 + 输入/缓存读/输出价`；保存时校验重叠与缺漏（禁止提交）
- **快速分档**：填阈值 → 「官方价补低档」自动生成低档=官方价，只填超档部分
- **分档计价开关 / 配比**：本模型级

## 4. 单次估算

选站/提供商 → 选模型 → 输入实际 tokens（入/读/写/出）→ 输出 `x.xxxx 代币 ≈ ¥y`（充比≠1 时附充比）。缓存写支持 TTL 选择：默认 5m，模型有 1h 档时可切。

## 5. 账单核对

贴 CSV / 传文件 / 载入示例 → 「核对」。CSV 列：调用时间,中转站,服务商,模型,输入,输出,缓存读,缓存写,实际扣费,备注。

- **备注语义**：Claude 系非空=按 1h 缓存写价、空=5m；闲忙模型非空=忙时、空=闲时
- **时间校验**：调用时间经官方 `peakWindows` 判定，与备注不一致的行**标黄**提示
- **理论扣费**：按当前配置计算（代币口径，与账单同单位）
- **误差判据**：勾「≤X%」=比例判据、勾「≤Y」=绝对值判据、都勾=取大者、都不勾=严格相等
- 结果逐行标 ✓一致 / 差值 / 找不到配置

## 6. 官方价目

全量模型表（id/厂商/档价区间/档位数/官方更新日/抓取日），右上角搜索。「一键更新」走后端 job：按钮变灰 → 日志滚动 → 汇总各厂商更新/新增/缺失。

## 7. 优先级速查

- **配比**：提供商 > 站 > 模型覆盖 > 模型级预设 > 厂商级预设 > 档案场景（默认 4/95/0/1）
- **折扣**：模型例外 > 厂商级 > 提供商默认 > 站默认 > 1
- **基价**：提供商覆盖 > 档案覆盖 > 官方
- **范围**：提供商 ⊆ 站（交集），商/站内为厂商×系列∪散选模型
- **分档开关**：档案 > 站 > 提供商 > 厂商 > 模型覆盖，全勾才分档
