# PRD — AI 中转站价格归一化计算器

版本：v0.1（发现阶段草案，待批准） · 日期：2026-11-24

## 1. 用户与问题

**用户**：通过中转站（one-api/new-api 类 API 代理站）购买模型额度的个人开发者。中转站通常以「官方价 × N 折」或自定价目表计费，不同站、不同模型折扣不一，且 token 配比（输入/输出/缓存命中）不同会显著改变实际成本。

**痛点**：官方价目按 输入/缓存读/输出 分列计费，无法直接回答「在我的用量结构下，这个站的 Claude Sonnet 5.5 每百万混合 tokens 实际多少钱？比那个站便宜吗？」

**目标**：一个本地运行的计算工具，输入各站折扣/自定价与用量假设，输出可横向比较的归一化单价（本币 + 折算币种两个价格）。

## 2. 范围

### 2.1 功能（v1）

| # | 功能 | 说明 |
|---|---|---|
| F1 | 官方价目库 | 内置 `data/models.json`（8 个厂商口径、~70 模型、分档价格、双币种）；只读浏览 + 可被用户覆盖修正 |
| F2 | 场景配置 | 假设上下文长度 `promptTokens`（决定命中价格档位）+ token 配比（输入%/缓存读%/输出%，自动归一化到 100%）+ 配比预设（保存/应用/删除多个命名预设） |
| F3 | 汇率 | USD↔CNY 汇率：手动输入 或 联网自动获取（显示来源与获取时间，可手动刷新，失败回退缓存值） |
| F4 | 中转站管理 | 站点 CRUD：名称、URL（备注用）、计价币种（USD/CNY）、全局默认折扣、启用开关、备注 |
| F5 | 模型级覆盖 | 每站每模型可设：单独折扣比例 **或** 完全自定义基础价（含自定义分档 tiers） |
| F6 | 全局模型覆盖 | 官方价修正（模型已涨价/价目过时）写为全局 override，优先级低于站内自定价 |
| F7 | 归一化结果表 | 行=模型（厂商分组、搜索、状态筛选 active/deprecated），列=官方 + 每个启用的中转站；单元格显示该币种归一化价与折算价双值；可按任一列排序；标注命中档位与无缓存价模型的回退规则 |
| F8 | 单次请求估算（辅助） | 输入实际用量（未命中输入/缓存读/输出 tokens 三个数），按相同规则输出单请求费用估算 |
| F9 | 配置持久化 | 全部配置经后端 API 持久化到 `data/config.json`；前端 localStorage 作离线降级缓存 |
| F10 | 导入导出 | 配置导出 JSON / 导入校验合并；一键恢复出厂默认 |
| F11 | 官方价目一键更新 | `python -m server.fetcher` / `POST /api/pricing/update`：逐厂商官方 `.md` 页抓取解析→合并回 models.json（只动厂商价目，**永不覆盖用户配置**）；直连失败自动走 v2rayN 节点池（VLESS+Reality→HY2，独立端口，不改 v2rayN 配置）；抓不到的厂商出人工核对清单；报告更新/新增/源中缺失/已下线 |
| F12 | 分档计价层级开关 | 账户→中转站→厂商→模型四级 `tieredPricing.enabled`；上级关闭则作用域内全部分档失效（按基础档计），但**不改写下级开关状态**，上级重开后原样恢复 |

### 2.2 非目标（v1 不做）

- 联网抓取各中转站实时价目表（手工维护，导入导出兜底分享）；
- Batch/Flex/Fast/Ultrafast、按次计费、音频/图片/视频模型、Embedding、免费层；
- 缓存写入费纳入配比（仅展示字段）；DeepSeek 非高峰价仅作模型开关项；
- 多用户/账号体系/云端同步；移动端专项适配（桌面优先，响应式可用即可）；
- 站内分组（group/分组倍率）建模 —— 以「多个站点条目」表达不同分组。

## 3. 核心概念与公式

### 3.1 归一化单价（每 1M 混合 tokens）

```
命中档位 tier = 价格表 tiers 中第一个满足 (upToTokens == null || promptTokens <= upToTokens) 的档
基础价 base   = 站内自定义价 ?? 全局官方价覆盖 ?? 官方 tier
折扣 discount = 模型覆盖折扣 ?? 站点默认折扣 ?? 1
单项价        = { input: base.input×d, output: base.output×d, cacheRead: (base.cacheRead ?? base.input)×d }
归一化价(本币) = input×mix.input + cacheRead×mix.cacheRead + output×mix.output     （mix 归一化和=1）
DeepSeek 类模型若开启非高峰：再 × offPeakRatio
```

- 换汇：币种 USD → `×rate` 得 CNY；CNY → `÷rate` 得 USD。表格每个单元格同时显示两个值（本币在前）。
- `cacheRead` 为空的模型：缓存读按 `input` 价计（多数厂商口径），UI 标注。
- `mix` 输入不强制和为 1，计算时自动归一化并显示归一化后百分比。

### 3.2 单次请求估算

```
费用(本币) = (未命中输入×input + 缓存读×cacheRead + 输出×output) / 1e6 × discount （档位按 未命中+缓存读 合计判定）
```

## 4. 页面与状态

单页应用，顶部标题栏 + 4 个区（锚点/页签切换）：

| 区 | 内容 | 关键状态 |
|---|---|---|
| 场景栏 | promptTokens 输入、三项配比、预设下拉、汇率（自动/手动切换、当前值、来源时间、刷新） | 配比和≠100% 时显示归一化后值；汇率获取 loading/失败回退提示 |
| 结果表 | 厂商筛选 chips、搜索框、状态筛选、排序表头 | 无站点→空态引导；无启用站→提示；某模型某站无覆盖也照常计算（用站默认折扣） |
| 中转站管理 | 站点卡片列表 + 编辑抽屉/弹层（基本信息 + 模型覆盖表：选模型→折扣或自定义 tiers 编辑器） | 表单校验（折扣 0<x≤10、价格≥0、tiers 按 upTo 升序且末档 null）；删除二次确认 |
| 官方价目 | 只读表格浏览全部模型与档位 + 「编辑官方价」入口（写全局 override，可还原） | 显示数据来源与 checkedAt |

通用状态：正常 / 空（首次无站点无配置）/ 加载（汇率、导入）/ 错误（API 不可达→降级 localStorage 并横幅提示；JSON 导入校验失败逐条报错）。

## 5. 验收标准（可验证）

1. 修改 promptTokens 使跨过某模型档位阈值（如 Haiku 5.5 的 100K），其官方列归一化价按高档重算并标注命中档。
2. 配比 70/20/10 与 7/2/1 计算结果一致（自动归一化）。
3. 站内模型折扣覆盖优先于站默认折扣；自定义基础价覆盖完全替代官方价（含档位）。
4. USD 站与 CNY 站同一模型的两个单元格均能同时显示 $ 与 ¥ 双价，换算方向正确。
5. 断网/关后端时页面仍可打开并提示降级；配置改动在刷新后仍在（localStorage）。
6. 导出 JSON 删除配置后导入可完整还原；篡改字段给出校验错误而非崩溃。
7. `node --test tests/` 单元测试覆盖：档位命中、归一化、折扣优先级、汇率双向折算、缺缓存价回退。
